What it would do

Connecting Stardrive with Asana through Zapier would allow you to:

  • Create a task for every contact form submission.
  • Assign tasks to the right team member based on the topic.
  • Set due dates and projects automatically.

How it would work

  1. Create a new Zap in Zapier.
  2. Use Stardrive as the trigger (e.g. “New Form Submission”).
  3. Use Asana as the action (e.g. “Create Task”).
  4. Map the task fields and activate.
